# Day 31 — Developer Assistant

AI Advent — Flutter-чат с ассистентом разработчика. Команда `/help` отвечает
по документации собственного проекта и получает реальную Git-ветку через MCP.
Обычные сообщения остаются обычным чатом с локальной Ollama `qwen3:4b`.

## Структура проекта

- `lib/main.dart` — Flutter UI: URL Gateway, Bearer-токен, история, ввод `/help`.
- `lib/local_llm_client.dart` — HTTPS-клиент `POST /v1/chat`, таймаут 6 минут.
- `gateway/gateway.py` — авторизация, ограничения, очередь, обычный чат и `/help`.
- `gateway/developer_assistant.py` — выбор источников, RAG, MCP-клиент, проверка цитат.
- `server/developer_server.dart` — MCP-сервер, единственный инструмент `get_current_branch`.
- `README.md` и `docs/**/*.md` — актуальная документация для RAG.
- `gateway/cloudflared.example.yml` — пример конфигурации HTTPS-туннеля.

Подробнее: [архитектура](docs/architecture.md), [RAG](docs/rag.md), [MCP](docs/mcp.md).

## Ручной запуск

Команды выполняются пользователем из корня существующего проекта.
Python 3.10+, Flutter SDK, Git, Ollama и при доступе с телефона `cloudflared`.

```sh
flutter pub get
ollama pull qwen3:4b
ollama pull embeddinggemma
```

Запустите установленное приложение Ollama либо `ollama serve` в отдельном
терминале, если сервер ещё не работает. Ollama слушает `127.0.0.1:11434`.
`embeddinggemma` нужна только для локальных embeddings RAG, ответы генерирует
`qwen3:4b`. Облачных LLM нет.

В отдельном терминале:

```sh
dart run server/developer_server.dart
```

MCP слушает `127.0.0.1:3000/mcp`. Корень проекта определяется по расположению
скрипта, а не по текущему каталогу терминала. Не публикуйте MCP наружу.

Создайте секрет и запустите Gateway в другом терминале:

```sh
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
export GATEWAY_TOKENS='YOUR_GENERATED_SECRET'
python3 gateway/gateway.py
```

Gateway слушает `127.0.0.1:8080`. Секрет — минимум 32 ASCII-символа.
Не сохраняйте его в git. Затем в отдельном терминале:

```sh
cloudflared tunnel --url http://127.0.0.1:8080
flutter run -d <DEVICE_ID>
```

Введите выданный HTTPS origin без пути и Bearer-токен в Flutter.
Для iPhone требуется настроенная подпись Xcode. Cloudflare передаёт запросы
на Gateway и может обрабатывать содержимое; Ollama и MCP доступны только локально.
Веб-клиент/CORS не реализованы. Для постоянного адреса можно использовать
`gateway/cloudflared.example.yml` с собственными hostname, UUID и credentials.

## Ручная проверка /help

1. `/help Как устроен проект?` — описание текущих файлов со ссылками на README/docs.
2. `/help Как реализован RAG?` — chunking, embeddings, cosine, top-3 и источники.
3. `/help Какая текущая Git-ветка?` — фактическое имя и источник MCP get_current_branch.
   Сравните с `git branch --show-current`. Переключите ветку вручную и повторите:
   результат должен обновиться без перезапуска MCP и без ручной настройки имени.
   Не переключайте ветку с несохранёнными изменениями без их сохранения.
4. `/help Как устроен проект и какая текущая ветка?` — оба источника.
5. Измените документ в `docs/` и повторите вопрос: индекс перестраивается при
   следующем RAG-запросе. Первый запрос медленнее из-за генерации embeddings.
6. Остановите MCP и спросите о ветке: ошибка сервиса, вымышленной ветки нет.
   В detached HEAD сервер сообщает отсутствие текущей ветки.
7. `/help` — подсказка синтаксиса; обычное сообщение — прежний чат.

Ссылки `README.md#L…` и `docs/…#L…` указывают файл и начало раздела.
Flutter показывает их как выделяемый текст, который можно скопировать;
отдельного просмотрщика документов нет. `mcp://developer/get_current_branch`
обозначает источник инструмента, это не веб-страница.

## Ограничения и проверки

HTTP API прежний: `POST /v1/chat`, JSON `{"messages":[{"role":"user","content":"/help Как устроен проект?"}]}`,
Bearer-авторизация. История хранится только в памяти Flutter. Для `/help`
используется текущий вопрос, предыдущие ответы не становятся источниками фактов.

6 запросов за 60 секунд на токен; до 24 чередующихся сообщений user/assistant;
тело до 32768 байт, история до 6000 UTF-8 байт. «Новый чат» очищает историю.
Одна активная генерация, три ожидающих; ожидание очереди до 160 секунд.
Ollama: `num_ctx=8192`, ответ до 512 токенов. RAG запрашивается лениво;
несколько последовательных локальных запросов могут занять время, туннель может
оборвать ожидание раньше клиента. Ошибки: 401, 400, 413, 429, 503, 502/504.
Обрезанные или невалидные ответы ассистента отклоняются.

При реализации не запускаются приложение, сервисы, API/LLM/MCP-запросы или тесты.
Разрешённые проверки: `flutter analyze` и компиляция Python через `compile`
без импорта/запуска. Runtime проверяется пользователем по шагам выше.
