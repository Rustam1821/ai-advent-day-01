# Проект Кедр — эксплуатация

Это вымышленная внутренняя спецификация для демонстрации RAG. Правила ниже относятся только к проекту Кедр, а не к Rust или общедоступному продукту.

## Повторные попытки

В проекте Кедр максимальное количество повторных попыток отправки события — 7 после первой отправки. Между повторными попытками выдерживается фиксированная пауза 13 секунд. После исчерпания попыток событие переводится в очередь ручного разбора.

## Хранилище

Основное хранилище проекта Кедр называется CedarVault. Резервные снимки создаются каждые 6 часов. Для демонстрации название обозначает внутренний компонент, а не внешний облачный сервис.

## Развёртывание

Окно развёртывания проекта Кедр — вторник, 02:40 UTC. Изменения вне этого окна требуют отдельного разрешения дежурного. Это правило не определяет время плановых резервных снимков.

## Ограничения пакета

В проекте Кедр один пакет передачи содержит не более 240 событий. Максимальный размер одного события — 48 КиБ. При превышении количества событий отправитель делит данные на несколько пакетов.
