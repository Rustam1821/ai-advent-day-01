# Настройки и ошибки чата

## Gateway и авторизация
В Flutter укажите HTTPS origin Gateway без пути и Bearer token из GATEWAY_TOKENS на Mac. HTTP 401 означает, что Gateway не принял токен: проверьте совпадение значения, отсутствие лишних пробелов и актуальность токена после перезапуска Gateway. Не отправляйте секрет в чат или тикет. Адрес туннеля может измениться после перезапуска cloudflared.

## История и ограничения
Support использует выбранный тикет и историю текущего диалога. Смена тикета, режима или кнопка «Новый чат» очищает историю. История и токен хранятся в памяти приложения до закрытия. До 24 сообщений и 6000 UTF-8 байт истории; при HTTP 413 начните новый чат, сохранив выбор тикета. HTTP 429: подождите время Retry-After. HTTP 502/504: проверьте доступность Ollama, embeddinggemma, qwen3:4b, MCP и корректность источников. Невалидные цитаты отклоняются, а не отображаются как подтверждённый ответ.
