# Локальная модель и Ollama

## Запуск и проверка Ollama
Локальная модель qwen3:4b работает на Mac через Ollama. Если в тикете ollama_status=stopped, по данным тикета Ollama остановлена; это не проверка состояния компьютера в реальном времени. Запустите приложение Ollama на Mac либо выполните `ollama serve` в отдельном терминале. Если порт занят, второй экземпляр запускать не нужно.

Проверьте сервер командой `curl http://127.0.0.1:11434/api/tags` на Mac: успешный HTTP-ответ с JSON models означает, что API Ollama доступен. Connection refused означает, что API недоступен по этому адресу; проверьте процесс и порт. `ollama list` показывает установленные модели, `ollama ps` — модели, загруженные в память. Пустой `ollama ps` не означает, что сервер остановлен.

## Модель не установлена
Выполните `ollama pull qwen3:4b` и проверьте `ollama list`. Ошибка model not found означает, что запрошенная модель отсутствует. Ассистент не запускает эти команды за пользователя.
