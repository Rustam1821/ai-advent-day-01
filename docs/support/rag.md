# RAG и база знаний

## Embeddings и поиск
RAG ищет фрагменты документации через локальную embeddinggemma. Ошибка model embeddinggemma not found означает отсутствие модели embeddings: на Mac выполните `ollama pull embeddinggemma`, затем повторите вопрос. qwen3:4b генерирует ответы, но не заменяет модель embeddings.

Документы поддержки находятся в docs/support/*.md. Индекс в памяти Gateway строится лениво, обновляется при изменении содержимого и исчезает при перезапуске. Если релевантных фрагментов нет, уточните вопрос или добавьте документацию; отсутствие результата не доказывает неисправность модели. Источники и дословные цитаты показываются под ответом.
