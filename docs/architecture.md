# Архитектура Developer Assistant

## Как устроен проект

Проект AI Advent состоит из Flutter-чата, Python Gateway и локального Dart MCP-сервера.
Flutter UI реализован в `lib/main.dart`; HTTPS-запросы выполняет `lib/local_llm_client.dart`.
Gateway в `gateway/gateway.py` проверяет Bearer-токен, лимиты и историю, затем
обрабатывает обычный чат или команду `/help`. Все генерации выполняет локальная
Ollama `qwen3:4b`, облачные модели отсутствуют.

## Команда /help

Для `/help <вопрос>` Gateway вызывает `gateway/developer_assistant.py`.
Сначала qwen3:4b возвращает JSON выбора источников documentation/branch.
Для маршрутизации и ответа Ollama получает строгую JSON-схему.
Вопросы о проекте и RAG направляются в документацию, о текущей Git-ветке — в MCP;
смешанные вопросы используют оба источника. Это решение модели, список фраз
с ручной подстановкой ветки не используется.

После получения источников qwen3:4b формирует ответ с citations.
Gateway проверяет существование id и дословность quote с нормализацией пробелов и переносов строк, добавляет ссылки.
Если источники не подтверждают ответ, ассистент сообщает недостаток информации.
Проверка цитат не доказывает семантическую поддержку каждого утверждения моделью;
её нужно оценить вручную при проверке ответов.

Для `/help` используется текущий вопрос без памяти задач и переписывания запросов.
Обычный чат отправляет историю в Ollama как прежде. Токен и история живут только
в памяти клиента; документация и Git доступны на Mac, а не в sandbox телефона.

## Что перенесено из предыдущих дней

Days 21–25: алгоритм StructureAwareChunker, метаданные chunks, embeddings
embeddinggemma, cosine ranking, top-K, контроль изменения корпуса и валидация
цитат. Dart RAG адаптирован к Python Gateway, чтобы читать актуальные файлы
проекта без упаковки устаревающей копии в Flutter assets.
Days 16–20: MCP initialize, notifications/initialized, discovery tools/list,
tools/call и закрытие сессии; Dart сервер использует тот же mcp_dart 2.4.2
и StreamableMcpServer/registerTool, что Day 20.

Не перенесены Rust-корпус documents/, облачный DeepSeek, Task State, сравнение
стратегий, старые задачи и отчёты, дополнительные MCP-инструменты и редактирование кода.
